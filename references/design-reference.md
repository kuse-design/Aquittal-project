# Storefront visual reference

The site owner provided this public page as a visual reference: https://kaizen-microfinance.vercel.app/ . The requested reuse was its colour and typography setup for a clothing-brand storefront, not its finance content.

The implemented apparel design uses a warm cream canvas (`#f7f5ef`), near-black text (`#080808`), muted gold accents (`#c9a227` / `#8a6d1b`), Satoshi sans-serif for interface text, and Instrument Serif for editorial headings. The layout is intentionally fashion-editorial: an announcement strip, compact navigation, asymmetric campaign hero, collection grid, brand-story section, and dark footer.
